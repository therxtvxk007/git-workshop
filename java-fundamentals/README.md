# Java Fundamentals — A Thinking Person's Monologue

This is not a textbook. It's the internal monologue of someone who knows only
MIT Scratch, sitting down with Java and *reasoning their way in* — hitting each
problem, analyzing it, and thinking their way out, instead of memorizing
structure.

Read it in order. Each part builds a mental model the next part leans on.

| Part | File | Covers |
|------|------|--------|
| 1 | [01-environment-compiler-jvm.md](01-environment-compiler-jvm.md) | The programming environment (command line & IDE), the compiler, the Java Virtual Machine |
| 2 | [02-data-arrays-strings-vector.md](02-data-arrays-strings-vector.md) | Primitive types & wrapper types, casting & autoboxing, arrays, Strings, the Vector class |
| 3 | [03-operators-and-precedence.md](03-operators-and-precedence.md) | Arithmetic, bitwise, relational, boolean logical, assignment, ternary operators; operator precedence |
| 4 | [04-control-flow-functions-args.md](04-control-flow-functions-args.md) | Selection, iteration & jump statements; functions; command-line arguments; variable-length arguments |
| 5 | [05-classes-abstract-interfaces.md](05-classes-abstract-interfaces.md) | Classes, abstract classes, interfaces — and the naming conventions that run through everything |

**The one rule of this whole series:** never accept "that's just how Java is."
Every rule exists because somebody hit a problem. Find the problem, and the rule
becomes obvious.
